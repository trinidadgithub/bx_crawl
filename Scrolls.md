# Scrolls

Scrolls are rare magical writings found in the dungeon. Only a Magic-User
may read an arcane scroll; only a Cleric may read a divine scroll. Once
read, the scroll crumbles to dust and the spell is cast as if memorised.

## Arcane Scrolls

### Charm Person


Charms a living humanoid within melee range. Undead are immune. The charm
breaks if the hero attacks the charmed target.

Reveals the presence of magical auras in the area. (Flavour — all

```

│ ∪ ∪ │
│  Θ  │
│ ─── │

```

A shimmering disc appears and follows the caster, carrying up to 5000

```
┌─────┐
│ │ │ │
│  Θ  │
│ │ │ │
└─────┘
```

Magically locks an adjacent closed door. The door cannot be opened by
normal means while held.

```

└─────┘
```

Bathes the area in magical light for 20 turns, radius 10 (torch is

```
│  Θ  │

└─────┘
```

Launches a dart of force that strikes the first target in a chosen
